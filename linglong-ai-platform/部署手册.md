## 一、部署架构概述

### 1.1 部署拓扑

```
用户浏览器 (公网)
       │
       ▼
  Nginx (80端口) ─── 静态文件 (linglong-ui/dist)
       │
       │ 反向代理
       ▼
  API网关 (8080端口)
       │
   ┌───┼───────┬──────────┐
   ▼   ▼       ▼          ▼
  8081 8085   8084       8083
  用户  Agent  LLM核心   MCP服务
  服务  服务   服务      服务
   │    │      │          │
   └────┴──────┴──────────┘
              │
    ┌─────────┼──────────┐
    ▼         ▼          ▼
  MySQL    PostgreSQL   Redis
  (3306)   (5432)      (6379)
```

### 1.2 服务器信息

| 项目 | 信息 |
|------|------|
| 云服务商 | 阿里云 ECS |
| 操作系统 | Linux (CentOS 7+ / Ubuntu 20.04+ / Alibaba Cloud Linux) |
| 公网IP | 8.137.117.129 |
| SSH工具 | Xshell |
| 部署路径 | `/opt/linglong/` |

### 1.3 服务端口分配

| 服务 | 端口 | 说明 |
|------|------|------|
| Nginx | 80 | 前端静态文件 + 反向代理 |
| linglong-gateway | 8080 | API网关 |
| linglong-user | 8081 | 用户服务 |
| linglong-mcp-server | 8083 | MCP工具服务 |
| linglong-llm-core | 8084 | LLM核心服务 |
| linglong-agent | 8085 | Agent服务 |
| MySQL | 3306 | 业务数据库 |
| PostgreSQL | 5432 | 向量数据库 |
| Redis | 6379 | 缓存服务 |
| MinIO | 9000 | 对象存储 |

### 1.4 安全组配置

在阿里云ECS控制台 → 安全组规则中，确保以下端口已放行：

| 端口 | 协议 | 授权对象 | 用途 |
|------|------|---------|------|
| 80 | TCP | 0.0.0.0/0 | Nginx前端访问 |
| 8080 | TCP | 0.0.0.0/0 | API网关（如需外部直接调用） |
| 22 | TCP | 办公网络IP | SSH连接（建议限制IP） |

以下端口仅服务器内部通信，**不需要公网放行**：
3306、5432、6379、9000、8081、8083、8084、8085

## 二、服务器环境配置

### 2.1 使用Xshell连接服务器

1. 打开 Xshell → 新建会话
2. 填写连接信息：
   - 名称：灵龙AI平台
   - 主机：8.137.117.129
   - 端口：22
3. 点击"用户身份验证"，输入用户名（root）和密码
4. 点击"连接"

### 2.2 创建部署目录

```bash
# 创建应用根目录
mkdir -p /opt/linglong

# 创建子目录
mkdir -p /opt/linglong/services    # 后端JAR包目录
mkdir -p /opt/linglong/logs        # 日志目录
mkdir -p /opt/linglong/uploads     # 文件上传目录
mkdir -p /opt/linglong/outputs     # Agent输出目录
mkdir -p /opt/linglong/repos       # Git仓库目录
mkdir -p /opt/linglong/backups     # 备份目录
mkdir -p /opt/linglong/scripts     # 运维脚本目录
```

### 2.3 安装JDK 21

```bash
# 方法一：使用包管理器（推荐 Ubuntu/Debian）
apt update && apt install -y openjdk-21-jdk

# 方法二：使用包管理器（CentOS/RHEL/Alibaba Cloud Linux）
yum install -y java-21-openjdk java-21-openjdk-devel

# 方法三：手动下载安装
wget https://download.oracle.com/java/21/latest/jdk-21_linux-x64_bin.tar.gz
tar -xzf jdk-21_linux-x64_bin.tar.gz -C /usr/local/
echo 'export JAVA_HOME=/usr/local/jdk-21' >> /etc/profile
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> /etc/profile
source /etc/profile

# 验证安装
java -version
# 预期输出：openjdk version "21.x.x"
```

### 2.4 安装Maven 3.6+

```bash
# 下载Maven
cd /opt
wget https://dlcdn.apache.org/maven/maven-3/3.9.9/binaries/apache-maven-3.9.9-bin.tar.gz
tar -xzf apache-maven-3.9.9-bin.tar.gz
mv apache-maven-3.9.9 maven

# 配置环境变量
echo 'export MAVEN_HOME=/opt/maven' >> /etc/profile
echo 'export PATH=$MAVEN_HOME/bin:$PATH' >> /etc/profile
source /etc/profile

# 验证安装
mvn -version
# 预期输出：Apache Maven 3.9.9 和 Java 21
```

```bash
ExecStart=/usr/local/bin/minio server /data/minio --console-address ":9001"
Environment="MINIO_ROOT_USER=minioadmin"
Environment="MINIO_ROOT_PASSWORD=minioadmin"
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 启动MinIO
systemctl daemon-reload

systemctl enable minio
```

## 三、数据库初始化

### 3.1 上传SQL脚本

使用Xshell的Xftp工具，将本地以下文件上传到服务器：

| 本地路径 | 服务器路径 |
|---------|-----------|
| `linglong-ai-platform/database/account.sql` | `/opt/linglong/backups/account.sql` |
| `linglong-ai-platform/database/platform-settings.sql` | `/opt/linglong/backups/platform-settings.sql` |
| `linglong-ai-platform/database/init-pgvector.sql` | `/opt/linglong/backups/init-pgvector.sql` |

**Xftp操作步骤**：
1. Xshell工具栏 → 点击"新建文件传输"（或 Ctrl+Alt+F）
2. 左侧（本地）导航到 `E:\OmniStack AI\linglong-ai-platform\database\`
3. 右侧（远程）导航到 `/opt/linglong/backups/`
4. 拖拽SQL文件到右侧窗口

### 3.2 执行MySQL初始化

```bash
# 导入用户账号表
mysql -u root -p123456 linglong < /opt/linglong/backups/account.sql

# 导入平台设置和LLM配置表
mysql -u root -p123456 linglong < /opt/linglong/backups/platform-settings.sql

# 验证：查看创建的表
mysql -u root -p123456 linglong -e "SHOW TABLES;"
# 预期输出：
# account
# platform_settings
# llm_providers
# database_configs
# external_tool_config
# chat_history

# 验证：查看默认用户
mysql -u root -p123456 linglong -e "SELECT id, username, role, mobile FROM account;"
# 预期输出：
# 1 | admin | 1 | 13800138001
# 2 | user  | 0 | 13800138002
```

### 3.3 执行PostgreSQL初始化

```bash
# 导入向量存储表结构
psql -h localhost -U linglong -d linglongpg -f /opt/linglong/backups/init-pgvector.sql

# 验证：查看vector_store表
psql -h localhost -U linglong -d linglongpg -c "\d vector_store"
# 预期输出：id(UUID), content(TEXT), metadata(JSONB), embedding(VECTOR(1024))

# 验证：查看HNSW索引
psql -h localhost -U linglong -d linglongpg -c "\di"
# 预期输出：vector_store_embedding_hnsw_idx

# 验证：查看自定义函数
psql -h localhost -U linglong -d linglongpg -c "\df"
# 预期输出：cosine_similarity_search, hybrid_search
```

## 六、Nginx配置

### 6.1 创建Nginx配置文件

```bash
# 备份默认配置
cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak

# 创建灵龙AI平台配置
cat > /etc/nginx/conf.d/linglong.conf << 'EOF'
server {
    listen 80;
    server_name 8.137.117.129;  # 替换为实际域名或IP

    # 前端静态文件
    root /opt/linglong/frontend;
    index index.html;

    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml text/javascript;
    gzip_min_length 1000;

    # 静态资源缓存
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # API代理 - 用户服务
    location /api/user/ {
        proxy_pass http://127.0.0.1:8080/api/user/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }

    # API代理 - Auth服务
    location /api/auth/ {
        proxy_pass http://127.0.0.1:8080/api/auth/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }

    # API代理 - Agent服务
    location /api/agent/ {
        proxy_pass http://127.0.0.1:8080/api/agent/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 600s;  # Agent执行和SSE需要长时间连接
    }

    # API代理 - MCP服务
    location /api/mcp/ {
        proxy_pass http://127.0.0.1:8080/api/mcp/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }

    # API代理 - LLM核心/AI服务
    location /ai/ {
        proxy_pass http://127.0.0.1:8080/ai/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;  # LLM调用耗时较长
    }

    # API代理 - 向量服务
    location /vector/ {
        proxy_pass http://127.0.0.1:8080/vector/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }

    # SSE流式传输专用配置
    location ~ ^/(api/agent/.*/stream|ai/conversation/stream|ai/document/stream) {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE必须禁用缓冲
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
        chunked_transfer_encoding on;

        # SSE响应头
        add_header Cache-Control no-cache;
        add_header X-Accel-Buffering no;
    }

    # SPA路由支持（所有非静态资源请求返回index.html）
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 健康检查端点
    location /health {
        return 200 'OK';
        add_header Content-Type text/plain;
    }
}
EOF
```

```bash
# 或重启Nginx
```

## 七、服务启动与停止

### 7.1 启动脚本

创建统一启动脚本：

```bash
cat > /opt/linglong/scripts/start-all.sh << 'EOF'
#!/bin/bash
# 灵龙AI平台 - 统一启动脚本

LOG_DIR=/opt/linglong/logs
SERVICE_DIR=/opt/linglong/services
JAVA_OPTS="-Xms256m -Xmx512m -XX:+UseG1GC"

echo "========================================="
echo "  灵龙AI平台 - 启动所有服务"
echo "  $(date)"
echo "========================================="

# 启动顺序：先启动基础服务依赖的服务，再启动网关
# 1. 用户服务 (8081)
echo "[1/5] 启动 linglong-user (8081)..."
nohup java $JAVA_OPTS -jar $SERVICE_DIR/linglong-user.jar \
    --server.port=8081 \
    > $LOG_DIR/user.log 2>&1 &
echo "PID: $!"

# 2. MCP服务 (8083)
echo "[2/5] 启动 linglong-mcp-server (8083)..."
nohup java $JAVA_OPTS -jar $SERVICE_DIR/linglong-mcp-server.jar \
    --server.port=8083 \
    > $LOG_DIR/mcp-server.log 2>&1 &
echo "PID: $!"

# 3. LLM核心服务 (8084)
echo "[3/5] 启动 linglong-llm-core (8084)..."
nohup java $JAVA_OPTS -jar $SERVICE_DIR/linglong-llm-core.jar \
    --server.port=8084 \
    > $LOG_DIR/llm-core.log 2>&1 &
echo "PID: $!"
```

### 7.4 单服务管理脚本

```bash
cat > /opt/linglong/scripts/service-ctl.sh << 'EOF'
#!/bin/bash
# 单服务管理脚本
# 用法: ./service-ctl.sh {start|stop|restart|status} {gateway|user|mcp|llm|agent}

ACTION=$1
SERVICE=$2

declare -A SERVICE_PORTS
SERVICE_PORTS[gateway]=8080
SERVICE_PORTS[user]=8081
SERVICE_PORTS[mcp]=8083
SERVICE_PORTS[llm]=8084
SERVICE_PORTS[agent]=8085

PORT=${SERVICE_PORTS[$SERVICE]}
JAR="/opt/linglong/services/linglong-$SERVICE.jar"
LOG="/opt/linglong/logs/$SERVICE.log"
JAVA_OPTS="-Xms256m -Xmx512m"

if [ -z "$PORT" ] || [ -z "$ACTION" ]; then
    echo "用法: $0 {start|stop|restart|status} {gateway|user|mcp|llm|agent}"
    exit 1
fi

case $ACTION in
    start)
        PID=$(lsof -ti:$PORT 2>/dev/null)
        if [ -n "$PID" ]; then
            echo "服务 $SERVICE 已在运行 (PID: $PID, 端口: $PORT)"
        else
            echo "启动服务 $SERVICE..."
            nohup java $JAVA_OPTS -jar $JAR --server.port=$PORT > $LOG 2>&1 &
            echo "已启动 (PID: $!)"
        fi
        ;;
    stop)
        PID=$(lsof -ti:$PORT 2>/dev/null)
        if [ -n "$PID" ]; then
            echo "停止服务 $SERVICE (PID: $PID)..."
            kill $PID 2>/dev/null
            sleep 3
            if kill -0 $PID 2>/dev/null; then
                kill -9 $PID 2>/dev/null
                echo "已强制停止"
            else
                echo "已停止"
            fi
        else
            echo "服务 $SERVICE 未运行"
        fi
        ;;
    restart)
        $0 stop $SERVICE
        sleep 2
        $0 start $SERVICE
        ;;
    status)
        PID=$(lsof -ti:$PORT 2>/dev/null)
        if [ -n "$PID" ]; then
            echo "服务 $SERVICE 运行中 (PID: $PID, 端口: $PORT)"
        else
            echo "服务 $SERVICE 未运行"
        fi
        ;;
    *)
        echo "未知操作: $ACTION"
        exit 1
        ;;
esac
EOF

chmod +x /opt/linglong/scripts/service-ctl.sh
```
