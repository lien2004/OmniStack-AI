## 一、服务架构总览

### 1.1 微服务列表

| 服务名称 | 端口 | 职责 | 技术栈 |
|---------|------|------|--------|
| linglong-gateway | 8080 | API网关、路由转发、鉴权 | Spring Cloud Gateway |
| linglong-user | 8081 | 用户认证、个人中心、平台设置 | Spring Boot + MyBatis Plus |
| linglong-agent | 8085 | Agent执行、工作流编排、项目管理 | Spring Boot + LangChain4j |
| linglong-llm-core | 8084 | LLM对话、RAG检索、向量存储 | Spring AI + pgvector |
| linglong-mcp-server | 8083 | MCP工具注册与执行 | Spring Boot + JPA |

### 1.2 调用链路

```
客户端 → Gateway(8080) → User/Agent/LLM/MCP Services
                                    ↓
                            PostgreSQL/MySQL/Redis
```

### 1.3 数据流向

- **用户请求**: Client → Gateway → Service → Database
- **向量检索**: LLM-Core → PostgreSQL(pgvector) → Embedding Model
- **Agent执行**: Agent Service → LLM-Core → MCP Tools → External APIs

## 二、统一响应格式

所有API接口返回统一的JSON格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1715673600000
}
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| data | Object/Array | 响应数据，失败时为null |
| timestamp | Long | 响应时间戳（毫秒） |

**成功响应示例**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "username": "admin"
  },
  "timestamp": 1715673600000
}
```

**失败响应示例**:
```json
{
  "code": 401,
  "message": "未授权访问",
  "data": null,
  "timestamp": 1715673600000
}
```

## 三、认证与授权

### 3.1 JWT Token机制

**Token获取**:
- 登录成功后返回JWT Token
- Token有效期: 24小时（可配置）
- Token格式: `Bearer <token>`

**Token使用**:
```http
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
```

**需要认证的接口**:
- 所有 `/api/user/profile/**` 接口
- 所有 `/api/agent/**` 接口（部分公开接口除外）
- 所有 `/ai/conversation/**` 接口
- 所有 `/vector/**` 接口（写入操作）

**无需认证的接口**:
- `/api/user/login`
- `/api/user/register`
- `/ai/generate` (只读)
- `/api/mcp/tools` (只读)

### 3.2 角色权限

| 角色 | 权限说明 |
|------|---------|
| 普通用户 (role=0) | 基础功能：对话、Agent执行、知识库查询 |
| 管理员 (role=1) | 全部权限 + 用户管理、系统配置 |

```python
import requests

API_BASE = 'http://localhost:8080'

def login(username: str, password: str) -> str:
    """用户登录"""
    response = requests.post(f'{API_BASE}/api/user/login', json={
        'username': username,
        'password': password
    })
    return response.json()['data']['token']

def execute_agent(token: str, agent_name: str, input_text: str) -> dict:
    """执行Agent"""
    headers = {'Authorization': f'Bearer {token}'}
    response = requests.post(
        f'{API_BASE}/api/agent/{agent_name}/execute',
        json={'input': input_text, 'autoSave': True},
        headers=headers
    )
    return response.json()['data']

def chat(token: str, chat_id: str, message: str) -> str:
    """多轮对话"""
    headers = {'Authorization': f'Bearer {token}'}
    response = requests.post(
        f'{API_BASE}/ai/conversation/chat',
        json={'chatId': chat_id, 'message': message, 'useRag': True},
        headers=headers
    )
    return response.json()['data']['answer']

def vector_search(query: str, top_k: int = 5) -> list:
    """向量搜索"""
    response = requests.get(
        f'{API_BASE}/vector/search',
        params={'query': query, 'topK': top_k}
    )
    return response.json()
```

### 10.3 Java示例

```java
import org.springframework.web.client.RestTemplate;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpEntity;
import java.util.Map;

public class LinglongClient {
    private static final String API_BASE = "http://localhost:8080";
    private final RestTemplate restTemplate = new RestTemplate();
    private String token;

    public void login(String username, String password) {
        Map<String, String> request = Map.of(
            "username", username,
            "password", password
        );
        Map<String, Object> response = restTemplate.postForObject(
            API_BASE + "/api/user/login",
            request,
            Map.class
        );
        this.token = (String) ((Map) response.get("data")).get("token");
    }

    public String executeAgent(String agentName, String input) {
        HttpHeaders headers = new HttpHeaders();
        headers.set("Authorization", "Bearer " + token);
        
        Map<String, Object> request = Map.of(
            "input", input,
            "autoSave", true
        );
        
        HttpEntity<Map<String, Object>> entity = new HttpEntity<>(request, headers);
        Map<String, Object> response = restTemplate.postForObject(
            API_BASE + "/api/agent/" + agentName + "/execute",
            entity,
            Map.class
        );
        
        return (String) ((Map) ((Map) response.get("data")).get("result"));
    }
}
```

### 11.1 性能优化

1. **使用流式接口**: 对于长文本生成，优先使用SSE流式接口
2. **缓存策略**: 对话结果会自动缓存到向量库，相同问题直接返回缓存
3. **批量操作**: 使用批量接口减少网络往返
4. **分页查询**: 大数据集使用分页避免内存溢出

### 11.2 安全建议

1. **HTTPS**: 生产环境强制使用HTTPS
2. **Token管理**: 定期刷新Token，避免长期有效
3. **敏感数据**: API密钥等敏感信息使用环境变量存储
4. **速率限制**: 启用网关限流防止DDoS攻击

### 11.3 错误处理

1. **重试机制**: 对 transient 错误实现指数退避重试
2. **超时设置**: 合理设置请求超时（建议30-120秒）
3. **日志记录**: 记录关键操作的请求和响应
4. **监控告警**: 集成APM监控服务健康状态
